# Professional Enterprise Identity Theme

This app implements the uploaded design system with:

- Deep navy primary actions and navigation
- Amber highlights for progress, active states, and attention signals
- Manrope typography
- 8px-based spacing
- Rounded enterprise card system
- Subtle navy-tinted shadows
- Fully rounded chips and badges
- Focus rings and input styles aligned with the design tokens
